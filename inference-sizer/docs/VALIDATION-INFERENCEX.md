# Inference Sizer against InferenceX

Generated by `node inference-sizer/tools/validate-inferencex.mjs --markdown`. Data: 125 measured runs (aggregated, one node) of DeepSeek-R1 on B200, H200, MI300X, B300, from a snapshot of the [InferenceX](https://github.com/SemiAnalysisAI/InferenceX) public API (runs dated 2026-05-18 to 2026-05-22; [snapshot](https://github.com/SemiAnalysisAI/InferenceX-app/blob/187628924b6ec899b1f3f771617655dd4cd61d8c/packages/app/cypress/fixtures/api/benchmarks.json), SHA-256 `f46823a76cb63248…`). For each run the sizer predicts the same layout (TP, DP-attention) at the same concurrency, input and output lengths and precision.

Error is how far off the prediction is either way, as a ratio: 40% means 1.4× too high or 1.4× too low. "Predicted ÷ measured" says which way: for TPOT, below 1 means the sizer predicts faster tokens than were measured; for throughput, above 1 means it predicts more than was measured. Both are the optimistic direction.
