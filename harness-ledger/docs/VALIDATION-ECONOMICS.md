## What it says

- **At one team's volume the API wins.** Self-hosting a frontier-size open model needs at least two whole nodes (one serving, one spare) whatever the load, so at this workload's volume it is cheaper only below the GPU-hour prices above, far under the $2–4 used in the volume table.
- **The crossover is a volume, and bursts move it.** On B200 at $3/GPU-hour self-hosting wins from about 11.3× this volume with this team's bursts, or 8.0× if peaks were flatter. Pooling many teams onto one fleet is what makes self-hosting pay.
- **Calls per task move the crossover, not the floor.** On SWE-bench DeepSeek V3.2 makes 1.83× the calls per task of Claude 4.5 Sonnet (high). At one team's volume that changes nothing (the two-node floor carries it); at the volumes where self-hosting could win it pushes the crossover out, because the open model has to serve that many more calls for the same work.
- **Context is a hard limit, not a cost.** 51% of this workload's calls are longer than DeepSeek V3's or Kimi K2's 128k context. They are capped here, which flatters self-hosting: those sessions would need compaction, or a model with a longer context.

## Fixes before any of this

Avoidable spend in this workload (relative units, as in VALIDATION-TRACELAB.md), worth doing whichever way the model is served:

| Fix | Share of spend |
| --- | --- |
| Cache expired during a pause | 17% |
| Context re-sent without a cache hit | 3.9% |
| Oversized tool output carried forward | 1.0% |
| Cache writes nobody read | 0.3% |
| Retrying a failing tool | 0.0% |

## Limits

- TraceLab has no task outcomes, so cost per resolved task uses SWE-bench resolution rates, from a different (benchmark) workload with one scaffold.
- The open model is assumed to make as many calls per task as the API model unless a row says otherwise; the SWE-bench calls ratio is a proxy measured on a benchmark, with calls of the same shape.
- Self-hosted cost is GPUs only (no power, staff or networking beyond the GPU-hour price), and the sizer's production defaults (whole nodes, one spare). `--no-spare` drops the spare.
