AIInfraTools · open source · Apache-2.0

Open tools for running GPU fleets

Size LLM inference, simulate capacity on a hybrid fleet, find why jobs fail or slow down, cap power, deploy on llm-d, and charge back every GPU-hour. Node.js and nothing else. Dry run by default, and a person approves every change.

One loop, from signal to verified fix

Observe→Diagnose→Simulate→Approve→Optimize→Verify
ToolWhat it does
fleetopsOne store for telemetry, jobs, serving and changes. Root-cause analysis, incidents, tuning from real traces, node admission and staged rollouts, power caps, fabric and storage stalls, one-command serving on vLLM and llm-d.
gpu-healthHealth checks, utilization and savings, with suggested fixes that run only once approved.
gpu-ledgerGPU-hours and cost by org, team, person and use case, split into useful, idle and lost; where to save, with an owner; FOCUS export.
inference-sizerGPU count, layout and cost at latency targets; what fits on given GPUs.
fleetscopeTraffic replay and capacity planning on a hybrid fleet.
hybrid-tracingOne trace view across sites, with clock-skew correction.

Install

Node.js 20+. No other dependencies.

npx aiinfra-tools demo          # the whole loop on a real cluster week
npx aiinfra-tools --help
npx aiinfra-tools sizer --model llama33-70b --gpu H100
npx aiinfra-tools ledger demo
